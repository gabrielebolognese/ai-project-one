# Corpus sources

All code is public, permissively licensed (**Apache-2.0** or **MIT**). Each licence was verified by
reading the repository's `LICENSE` file (see `src/corpus/clean.ts: detectLicense`), not assumed.
The raw clones live in `data/raw/` and the cleaned shards in `data/corpus/` (both gitignored); this
file is generated by `npm run corpus` (`scripts/fetch-corpus.ts`).

Splits are **by repository** (no file of a held-out repo is ever seen in training; files of a held-out
repo that duplicate a training file were dropped from the held-out side).

Training repos are capped at 15 % of the training bytes (cap 12.21 MB), selecting files in hash order, so that no
single code base dominates a 1M-parameter model.

## Considered and rejected

- `junit-team/junit4`: licence EPL is not Apache-2.0/MIT (EPL is weak copyleft; this corpus is Apache-2.0/MIT only).

## Also considered, not used

- `ben-manes/caffeine` (Apache-2.0) and `zxing/zxing` (Apache-2.0): their shallow clones stalled in `git index-pack` on this machine (three attempts, 8-minute timeout); the corpus already reached the token target without them.

## Cleaning rules

- only `*.java` (no `module-info.java` / `package-info.java`); raw file <= 100 KB, cleaned file >= 200 B
- dropped: generated code (`@Generated`, protobuf, "DO NOT EDIT"), invalid UTF-8, > 2 % non-ASCII, lines > 600 chars, no type declaration
- licence/copyright header comments stripped; CRLF to LF, tabs to 4 spaces, trailing spaces removed, 4+ blank lines collapsed
- de-duplicated: exact (hash of the cleaned file) and near (hash of the first 2 KB of the body without `package`/`import` lines)
